# Birthday Surprise ❤️

A dark-pink romantic birthday website made for GitHub Pages.

## Upload to GitHub

1. Create a new GitHub repository (for example: `birthday-surprise`).
2. Upload **all files and folders** from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will give you a website link.

## Music autoplay note

The page attempts to start the uploaded instrumental automatically. Modern browsers can block audible autoplay until the visitor interacts with the page. If that happens, the music starts on the first tap/click. The small ♫ button can also pause/play it.

## Personalize

Edit `index.html` if you want to change the wording, title, or add more memories.
